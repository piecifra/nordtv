NordLynx (WireGuard) runs on the TV itself. Changing the country or the kill switch reconnects the VPN when it is on. Your home network, Vetro included, stays reachable; DNS goes to NordVPN and IPv6 is blocked while the VPN is on. Reconnecting needs this plugin switched on.

Access token

Create one in Nord Account → NordVPN → Set up NordVPN manually → Generate new token. It is kept on the TV only (/opt/nordtv/token) and never shown again.
