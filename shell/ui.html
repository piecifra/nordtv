Runs commands on the TV as root, one at a time. Each command starts a fresh shell (bash if the TV has it): cd is remembered, variables and aliases are not. Programs that need a terminal or keyboard input (vi, top, less) do not work; use top -b -n 1, cat and the like. Other Vetro actions wait while a command runs.

Anyone who can use this dashboard can use this shell. A command can damage the TV's system: read it before you run it.
